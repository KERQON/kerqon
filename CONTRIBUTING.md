# Contributing to KERQON

Thank you for your interest in KERQON.

## Current phase

KERQON is in **early private development**.

This public repository is a **pre-code presence**: branding, community files, and coordination ahead of the first public source release.

**Source code will be published with the first public KERQON release.**

## What you can do now

- Suggest documentation or community improvements via issues
- Report security concerns via [SECURITY.md](SECURITY.md) — not as public issues
- Follow announcements at [kerqon.de](https://kerqon.de)

## Future code contributions

When public source is available:

1. Read [SECURITY.md](SECURITY.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)
2. Open an issue before large changes
3. Follow the contribution and review process published with the first release

Until then, please do not submit pull requests that expect product code to exist in this repository.
