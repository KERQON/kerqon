# Security Policy

## Supported versions

KERQON is in **early private development**. Security reports are accepted for the public presence and for coordinated disclosure related to the upcoming public product.

There is **no formal SLA** until the first public release.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Preferred options:

1. Use **GitHub Security Advisories** for this repository when available.
2. Use the contact path published on [kerqon.de](https://kerqon.de) when a dedicated security channel is listed.

Include:

- a clear description of the issue
- reproduction steps where possible
- affected component or surface
- impact assessment

Allow up to **72 hours** for an initial acknowledgement once a contact path is active.

## Disclosure

We prefer coordinated disclosure after a fix or mitigation is available.

## Scope

This policy covers:

- the public KERQON GitHub presence (README, community files, media, templates)
- published KERQON product artifacts and source **after** the first public release

Until source is published, treat product-related reports as coordinated and private.
